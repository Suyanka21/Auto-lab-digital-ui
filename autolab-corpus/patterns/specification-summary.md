# Specification Summary Pattern

## Objective

Display the customer’s current configuration clearly and accurately.

## Required fields

- Material.
- Primary colour.
- Secondary colour, where applicable.
- Accent thread.
- Composition.
- Trim selection, if applicable.
- Ambient illumination selection, if applicable.
- Active camera.

## Presentation

Use a structured specification format:

```text
MATERIAL          Diamond Quilted
PRIMARY COLOUR    Sienna Brown
SECONDARY COLOUR  Light Ivory
ACCENT THREAD     Cyan
COMPOSITION       Two-tone
CABIN TRIM        Walnut Wood — illustrative
AMBIENT LIGHT     Ocean — illustrative
CAMERA            Cockpit & Dash
```

## Rules

- Clearly mark illustrative choices.
- Do not display prices.
- Do not display availability.
- Do not display delivery timelines.
- Do not imply backend submission or order placement.
- Keep the summary readable on mobile.
