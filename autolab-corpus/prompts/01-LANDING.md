# Prompt 01 — Landing Page

Use after the design foundation is complete.

```text
Using the AutoLab design corpus, build only the Landing / Sales Experience.

Follow `patterns/landing-page.md`, `rules/visual-direction.md`, `rules/anti-slop.md`, and `rules/responsive.md`.

Create a polished editorial landing page with:

- AutoLab branding and compact navigation.
- A cinematic automotive-interior hero.
- Headline: “Make it personal.”
- Supporting copy about exploring bespoke interior materials, colours, and finishes.
- Primary CTA: “Enter the Studio.”
- Editorial sections for Material, Colour, Cabin Trim, and Ambient Illumination.
- High-quality material imagery with consistent framing.
- A brief explanation of how the configuration experience works.
- A clear route into the interactive Studio.

Design direction:
- Warm ivory background.
- Dark automotive presentation surfaces where appropriate.
- Restrained cyan accents.
- Editorial serif display headings.
- Clean sans-serif interface type.
- Generous whitespace.
- Fine borders and subtle surface separation.
- Premium automotive-atelier character.

Do not:
- Use a generic AI landing-page hero.
- Use purple-blue gradients.
- Use glassmorphism, neon glow, floating blobs, or decorative particles.
- Use fake testimonials, fabricated statistics, invented awards, or unsupported pricing.
- Use generic equal-width three-column feature grids unless editorially justified.
- Claim that automotive imagery represents the final interactive 3D model.

Before coding, state:
1. The reference pattern you are following.
2. The intended visual hierarchy.
3. The sections you will build.
4. The motion approach.
5. The anti-slop checks you will apply.

Then implement only the landing page. Do not build the configurator yet.
```
