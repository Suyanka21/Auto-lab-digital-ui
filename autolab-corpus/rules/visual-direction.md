# Visual Direction

## Brand

**AutoLab Interior Studio**  
Nairobi, Kenya

Direction: **Editorial Atelier**  
Character: refined, tactile, automotive, editorial, premium.

## Palette

Use only these core colours:

| Token | Hex | Use |
|---|---:|---|
| `ivory` | `#F3F0E9` | Primary page background |
| `paper` | `#FAF8F3` | Cards, panels, elevated surfaces |
| `ink` | `#252425` | Primary text |
| `graphite` | `#101114` | Dark presentation surfaces, viewer stage |
| `cyan` | `#72C4E1` | Precise accent, active state, focus indicator |
| `cyan-ink` | `#17596D` | Deep accent / selected-state support |
| `muted-grey` | `#65615B` | Secondary text, captions, labels |
| `fine-border` | `#D2CEC5` | Hairline borders and dividers |

Cyan is an accent, not a theme colour. It must not dominate backgrounds, headings, buttons, or large surfaces.

## Typography

Use an elegant, properly licensed editorial serif for display headings.

Use a clean, properly licensed sans-serif for interface controls, body copy, labels, and specifications.

Type hierarchy:

- Display: large, restrained, editorial serif.
- Section heading: smaller serif or refined sans-serif.
- Body: highly readable sans-serif.
- Labels: compact, uppercase or letterspaced sans-serif where appropriate.
- Specifications: tabular or structured, with clear label/value relationships.

Avoid decorative display fonts, excessive letter spacing, all-caps body copy, and oversized gradients.

## Layout principles

- Use generous whitespace.
- Use clear visual hierarchy.
- Prefer asymmetric editorial composition over mechanically centered layouts.
- Use hairline borders and subtle surface separation.
- Let automotive material imagery carry visual weight.
- Avoid equal-width three-column feature grids unless genuinely justified.
- Avoid dashboard-like panels, dense stat blocks, and generic SaaS cards.

## Surface treatment

- Warm ivory backgrounds for editorial areas.
- Graphite or near-black surfaces for the cabin viewer and premium presentation areas.
- Paper surfaces for configuration controls and specification summaries.
- Fine borders rather than heavy shadows.
- Restrained shadows only where depth improves legibility.

## Imagery

Use high-quality automotive upholstery, leather, stitching, trim, and cabin imagery.

Imagery must communicate the actual selected material:

- Smooth leather for Classic.
- Diamond quilting for Diamond Quilted.
- Perforation for Perforated.
- Contrast stitching where relevant.
- Carbon-fibre weave for Carbon Fibre.
- Open-pore wood for Poplar or Walnut.
- High-gloss lacquer for Piano Lacquer.

Do not reuse one brown seat photograph for every material selection. Label illustrative imagery clearly.
