# Asset Instructions

## Reference imagery

Use the supplied reference images as visual direction.

Do not claim that generated automotive photography represents the final interactive 3D model.

## Required imagery

Use convincing automotive upholstery and close-up material references for:

- Smooth leather.
- Diamond quilting.
- Perforated leather.
- Contrast stitching.
- Carbon-fibre weave.
- Open-pore wood.
- Piano lacquer.

## Rules

- Do not reuse one brown seat photograph for every material.
- Ensure material imagery matches the selected material.
- Label illustrative imagery clearly.
- Use appropriately licensed assets.
- Avoid misleading mismatches, such as perforated leather shown under Classic.

## Logo

Use the supplied AutoLab logo if available.

Do not invent a replacement logo.
