# Configuration Panel Pattern

## Objective

Create a calm, precise configuration panel that makes selections easy to understand and edit.

## Layout

Use a narrow right-side panel on desktop.

Use a compact bottom or side panel on mobile.

Include:

- Step indicator.
- Previous / next controls.
- Option selectors.
- Selected-state feedback.
- Specification summary access.
- Clear illustrative-option labels.

## Selector design

Each selector must show:

- Option name.
- Visual representation where useful.
- Selected state.
- Optional short description.
- Accessible focus state.

Avoid tiny colour swatches without labels.

## Material selector

Show materially distinct previews:

- Classic: smooth leather.
- Diamond Quilted: quilted pattern.
- Perforated: perforated leather.

## Colour selector

Show:

- Exclusive Black.
- Sienna Brown.
- Light Ivory.

Clearly identify any additional colours as illustrative.

## Thread selector

Provide selectable thread colours with visible selected states.

## Composition selector

Provide:

- Single-colour.
- Two-tone.

Explain affected surfaces.

## Trim and illumination

Treat these as illustrative previews:

- Carbon Fibre.
- Poplar Wood.
- Walnut Wood.
- Piano Lacquer.
- Cyan, Amber, Rose, Ocean, Champagne illumination.

Do not imply commercial approval unless AutoLab confirms it.
