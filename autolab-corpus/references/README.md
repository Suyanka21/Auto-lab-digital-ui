# Reference Manifest

The attached visual references define the intended standard. They are **art direction**, not pixel-perfect screenshots to reproduce.

## Reference 01 — Visual Direction & Design System

Use for:

- Warm ivory background.
- Dark automotive presentation surfaces.
- Restrained cyan accents.
- Typography hierarchy.
- Leather and material texture.
- Minimal editorial styling.

## Reference 02 — Desktop Configurator

Use for:

- Large automotive viewing stage.
- Compact right-side configuration panel.
- Camera controls.
- Material options.
- Clear selection states.

## Reference 03 — Mobile Configurator

Use for:

- Mobile-first viewing experience.
- Accessible controls.
- Compact navigation.
- Generous cabin presentation.

## Reference 04 — Landing / Sales Experience

Use for:

- Cinematic introduction.
- Premium editorial layout.
- Feature cards.
- Prominent entry into the configurator.

## Interpretation rules

- Extract visual grammar, not exact pixels.
- Preserve hierarchy, spacing rhythm, surface treatment, and material realism.
- Do not copy automotive imagery, logos, or proprietary layouts exactly.
- Do not invent a replacement AutoLab logo.
- If the supplied AutoLab logo is available, use it.
