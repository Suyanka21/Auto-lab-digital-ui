# Responsive Rules

## Target viewports

- Desktop: 1440 × 900
- Mobile: 390 × 844
- Intermediate widths must degrade gracefully.

## Desktop

- The cabin viewer should occupy approximately two-thirds of the working area.
- Configuration controls occupy a focused right-side panel.
- Navigation should be compact and unobtrusive.
- Material imagery should be large enough to communicate texture.

## Mobile

- The cabin viewer remains the dominant visual element.
- Configuration controls appear below the viewer or in a compact, touch-friendly panel.
- Do not shrink the viewer into a small decorative image.
- Use large tap targets.
- Avoid horizontal scrolling.
- Preserve legible type sizes.
- Keep step navigation accessible without excessive scrolling.

## Configuration controls

- Each option must have a clear selected state.
- Selected state must be visible without relying on colour alone.
- Use accessible focus states.
- Ensure controls are usable with touch.
- Avoid tiny swatches or cramped labels.

## Performance

- Use responsive images where practical.
- Avoid unnecessary animation libraries.
- Avoid large unoptimized images.
- Do not animate expensive properties on low-powered devices.
