# 3D workspace rules

Read `/DEVIN_START_HERE.md` and the current owner's task before making changes.

- `workspace/` is immutable handover evidence and archived checkpoints. Restore it into a separate scratch directory for reproduction. Create future component work in a new clearly named area/branch.
- `workspace/working_models/R4-front-door-refined.blend` is visually approved as a benchmark only. No runtime promotion follows from that approval.
- The repository-root `AUTOLAB_INTERIOR_3D_REFERENCE_PACK/` retains primary design authority. Alternates supplement depth; old 35-photo-primary instructions in historical reports are superseded for visible bespoke design.
- Read `.agents/skills/autolab-premium-cabin-modeling/SKILL.md` for modelling. Do not copy the front door's dimensions or topology into unrelated components.
- Preserve production files, seven live bindings, three treatments and loaders unless a separate explicit task authorises changes. Archived original finalizers can write into public/; never run them directly against the app checkout.
- Do not infer permission to model another component, change budgets, merge, deploy, transfer to another service or delete local files.
- Record actual evidence and retain limitations. Do not claim OEM fit, browser equivalence or phone performance from a Blender render.
