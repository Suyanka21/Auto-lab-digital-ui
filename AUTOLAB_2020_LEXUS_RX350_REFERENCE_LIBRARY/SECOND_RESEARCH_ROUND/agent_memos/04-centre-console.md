# 2020 Lexus RX 350 AWD five-seat — centre-console / selector / Remote Touch / storage reference memo

**Research scope.** This memo covers the 2020 Lexus RX 350 AWD in the U.S. market, five-seat RX (not the RX 350L three-row derivative), with emphasis on the centre console, shift selector, Remote Touch/touchpad, cupholders, front armrest, storage and trim. It records exact URLs, source identity, evidence class and rights/provenance status. No dimensions are inferred from photographs or prose.

## Findings that are safe to carry into a reference package

The 2020 RX 350 five-seat cabin retained Lexus Remote Touchpad controls on the centre console while adding a driver-closer touchscreen: the official Lexus newsroom describes a standard 8-inch or optional 12.3-inch touchscreen for all 2020 RX models, and the 2020 brochure lists both the Lexus Multimedia System with touchscreen display and Remote Touchpad as standard equipment. [1] [2] Independent period reviews confirm that the touchpad remained physically present on the console and was partly redundant once the touchscreen arrived. [3] [4]

The centre console has a dedicated upright smartphone pocket/slot. Cars.com reviewers describe it as a sizable, vertical holder that keeps a phone from sliding out during acceleration. The same sources establish an important functional limitation: the nearby USB ports are charge-only, while the data connection for CarPlay/Android Auto is in the console storage bin, requiring a cable to cross toward the phone/cupholder area. [3] [4]

The official brochure establishes the general material and trim vocabulary: base RX interiors use NuLuxe; available packages add semi-aniline leather, wood trim and aluminum accents; F SPORT uses Circuit Red NuLuxe with Scored Aluminum in the shown configuration and adds a sport steering wheel/shift knob and aluminum pedals. It also lists six USB ports, dual-zone automatic climate control, a leather-trimmed steering wheel and shift knob, and Remote Touchpad as standard. [2] These are equipment/package claims, not proof that every 2020 RX 350 AWD carried the same visible trim.

A period road test identifies the reviewed vehicle as a 2020 RX 350 F Sport AWD with the F Sport Performance package and calls the centre console “too busy.” It confirms the touch screen, climate/radio controls below it, and continued Remote Touchpad use, but it does not document the base/non-F-Sport console finish. [5]

## Practical visual/reference guidance

For a centre-console reference board, prioritize the official Lexus 2020 RX media URLs from [1] as exact-year appearance anchors, but label whether the selected image is RX 350 F SPORT or another package before using it to infer trim. Use the Cars.com exact-year photographs and prose [3] [4] for the phone slot, touchpad placement and cable/USB relationships. Use CarPro [5] for close related AWD/F Sport context and the “busy” control-stack observation. Use the dealer guide [6] only for supporting vocabulary such as NuLuxe, self-gripping cup holders and premium trim/package names. Correction (2026-11-17): the three images from [1] held in this library (`2020_Lexus_RX_350_0049.jpg`, `0051.jpg`, `0052.jpg`) are exterior photographs and must not be used for console appearance; no other frame from that gallery was inspected. The interior photographs held in the library that show the console are `LEXUS_RX_2020_GALLERY_07.jpg`, `_19.jpg`, `_33.jpg` and `_34.jpg` in `00_GALLERY_ORIGINALS/` (one donor vehicle, internal modelling reference only; see `RIGHTS_AND_USE.md` there).

Do not merge the following into a single universal rendering: base RX 350 NuLuxe, F SPORT Scored Aluminum/Circuit Red NuLuxe, Luxury Package semi-aniline leather/wood, and RX 350L rear-armrest storage. They are distinct equipment contexts. The exact-year evidence supports a common console architecture, but upholstery, inlay, steering/shift-knob treatment and some storage/trim details vary by trim and package.
